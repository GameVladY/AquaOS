**AquaOS** is an independent, x86/x86_64 operating system built completely from scratch—without relying on the Linux kernel or existing OS distributions. It features a custom boot sequence with a detailed system loader, a dual-mode interface transition, and an interactive graphical desktop environment with full keyboard and mouse support.

---

## 🌟 Key Features

- **Built Entirely from Scratch:** Independent kernel and driver design, created without using external OS base layers or Linux source code.
- **Dual Architecture Support:** Designed to build and run on both 32-bit (`i686`) and 64-bit (`x86_64`) instruction sets.
- **Verbose Boot Loader:** Displays real-time kernel initializations, hardware probes, and resource mounting progress inside a detailed terminal boot screen before launching the GUI.
- **Graphical Desktop Environment:** Complete with a desktop interface, interactive taskbar, and hardware input integration for both keyboard and mouse.
- **Rich Core Resources:** Includes built-in system utilities, modular resource packages, and basic userland tools to provide a functional base environment.
